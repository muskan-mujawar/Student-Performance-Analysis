# Student-Performance-Analysis
Data analysis using Python (Internship Task 1)
## Project Overview
This project analyzes student performance data using Python to identify key factors affecting academic results.
## Objectives
- Understand student performance trends
- Analyze impact of study time, absences, and internet access
- Generate useful insights

## Tools Used
- Python
- Pandas
- Matplotlib

## Dataset
- student-mat.csv
- student-por.csv

## Key Insights
- Study time positively impacts performance
- Absences negatively affect grades
- Internet access improves learning outcomes
- Most students fall in average performance range

## Visualizations
- Bar charts
- Histograms
- Scatter plots

## Conclusion
This analysis shows that consistent study habits and attendance play an important role in improving student performance.
